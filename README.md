# TradePilot 🚀

TradePilot is a full-stack paper trading platform that allows users to simulate stock market trading using virtual money.  
The platform provides a realistic trading experience with portfolio management, stock tracking, and modern responsive UI.

---

# 🌟 Features

## 📈 Trading Features
- Buy Stocks
- Sell Stocks
- Portfolio Tracking
- Holdings Management
- Virtual Wallet System
- Order History
- Real-Time Stock Data Integration

---

## 🎨 Frontend Features
- Modern Responsive UI
- Light/Dark Mode
- Interactive Dashboard
- Real-Time Market Updates
- Trading Panels
- Portfolio Analytics
- Mobile Responsive Design

---

## ⚙️ Backend Features
- REST API Architecture
- Secure Authentication
- PostgreSQL Database Integration
- Trade Execution APIs
- Portfolio Calculation Engine
- Environment Configuration Support
